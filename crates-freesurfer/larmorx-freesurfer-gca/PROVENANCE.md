# Provenance: larmorx-freesurfer-gca

**Replica: translated from FreeSurfer's source.** This crate holds `fs.gca` (wave 3.3) of the FreeSurfer
replica (`docs/freesurfer/waves.md` section 4): GCA atlases and GCA morphs (`.gca`, `.m3z`), the linear GCA nodes, MRI morphs, FLASH and the autoencoder. It is distributed under FreeSurfer's
licence (`LicenseRef-FreeSurfer`, `../LICENSE`: the FreeSurfer Software License with its required
preface), as part of the `larmorx-freesurfer` package (`docs/licensing.md`).

The upstream is FreeSurfer 8.2.0 (GitHub's `v8.2.0` archive, SHA-256
`bb1699f7655ebf0f3790db6a78af9532ea7c832c97fe5f71bfd9f0e9526d7e78`; `docs/freesurfer-plan.md`),
built for the official binaries with GCC 8.4.0 (`docs/freesurfer/variation.md`).

## Changes from the originals

The grids are read through a buffer (FreeSurfer's `fread` is buffered; the port's plain file is not): the same
numbers, messages (`znzreadInt: znzread failed`, `freadFloat: fread failed`) and FS-167 notices as fs.io's readers;
the file is positioned back before the tagged section, read number by number. Each voxel's prior point is computed
once for its node and its prior (FreeSurfer computes it twice, identically). The defaults of FS-749 to FS-759 and
their notices are larmorx's own; the D13 switch `reproduce` gives FreeSurfer's behaviour where it is defined
(`docs/findings/freesurfer-io.md` Part 29, `specs/freesurfer-io.md` §132).

Relay 38 (the morphs): the metric properties are computed on one thread in x-major order (FreeSurfer's OpenMP loop
gives the same values; only `SHOW_NEG`'s lines differ in order, FS-852); the `width < 4` line's once-per-process
flag is `Globals::gcam_metric_width_reported`; the Voronoi diagram of an index volume is given a copy of it as its
source (FreeSurfer passes the same volume twice; the source is read only before it is written); the defaults of
FS-851 to FS-855 are larmorx's own (`docs/findings/freesurfer-io.md` Part 33, `specs/freesurfer-io.md` §142).
