# Provenance: larmorx-freesurfer-networks

**Replica: translated from FreeSurfer's source.** This crate holds the N track's programs of the FreeSurfer
replica (`docs/freesurfer/waves.md` section 4): the v8 stream's network programs (`mri_synthstrip`, `mri_synthseg`, `mri_synthmorph`, `mri_sclimbic_seg`: Rust inference with the original weights), their scripts and the programs only those scripts run. It is distributed under FreeSurfer's
licence (`LicenseRef-FreeSurfer`, `../LICENSE`: the FreeSurfer Software License with its required
preface), as part of the `larmorx-freesurfer` package (`docs/licensing.md`).

The upstream is FreeSurfer 8.2.0 (GitHub's `v8.2.0` archive, SHA-256
`bb1699f7655ebf0f3790db6a78af9532ea7c832c97fe5f71bfd9f0e9526d7e78`; `docs/freesurfer-plan.md`),
built for the official binaries with GCC 8.4.0 (`docs/freesurfer/variation.md`).
