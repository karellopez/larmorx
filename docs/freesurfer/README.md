# FreeSurfer 8.2.0: the inventory

**Closed to FreeSurfer clean-room implementers.** Everything in this folder is written from
FreeSurfer's source (`<workspace>/tags/freesurfer-8.2.0`, the scripts and Python of the installed
package) by replica-side agents (`docs/porting-guide.md` §1). A clean-room implementer of any
FreeSurfer program must not open, search or list the files of this folder; what it needs comes
through `specs/<program>.md`, written by the spec writers of each wave.

This is step 3.0 of [the FreeSurfer plan](../freesurfer-plan.md) ("3.0 Preparation", item 3): the
programs, the code each needs, the third-party audit, the data files, variation, the waves and the
porting cards. It grows relay by relay; the state of each part is below.

| File | What it holds | State |
|---|---|---|
| [programs.md](programs.md) | every program `recon-all` 8.2.0 runs in its two streams (v8, the default, and `-no-v8`), and the FreeSurfer programs fMRIPrep 25.2.6 and sMRIPrep 0.19.2 run outside it, each with the options used and the step that runs it; the corrections this brings to the plan | relay 1, from the script; to be checked against the recordings when they exist |
| [programs.toml](programs.toml) | the same, one entry per program, machine-readable (the base the cards and the queue are built from) | relay 1 |
| [code.md](code.md) | per program: its source files, the libraries it links, its compile flags, the shared library functions it reaches and their size; the foundations (the base layer, the clusters by file); the Python programs' imports and the package's Python versions | relays 1 and 2 |
| [code.toml](code.toml) | the same per program, machine-readable (generated by `report_code.py`; the porting cards are built from it) | relay 2 |
| [third-party.md](third-party.md) | the licence and origin of every file in those call graphs, the bundled packages' terms, the code inside FreeSurfer's files that comes from elsewhere (16 findings) and what each means for porting; the questions; the placement table of every third-party piece (its package, whether its licence combines with FreeSurfer's in one program, the process boundaries, the permissions needed, §9); ITK 4.13.2 against 5.4.5 (§10) | complete (relays 2, 3 and 5) |
| [placement.toml](placement.toml) | the placement table, one `[[piece]]` per third-party piece, with FreeSurfer's licence terms that decide each combination (written by hand) | relay 5 |
| [itk-diff.toml](itk-diff.toml) | ITK 4.13.2 against ITK 5.4.5 for every class FreeSurfer's default paths can compile in: statuses, sizes, the reading of each computing class that differs (generated by `itk_diff.py`) | relay 5 |
| [third-party.toml](third-party.toml) | the same, machine-readable: the findings with the programs reaching each, and every file with its notice, licence family and porting class (generated by `licences.py`) | relay 3 |
| [data-files.md](data-files.md) | every file of the package a default-path program reads at run time (measured: each recorded step run again under `strace`), its size, SHA-256, git-annex key, licence and origin, where FreeSurfer serves it on its own, the networks' weights, the home the plan's data rules give it | relay 4 |
| [data-files.toml](data-files.toml) | the same, one `[[file]]` per file, machine-readable (the plan's data rule 4; generated by `data_files.py`) | relay 4 |
| [variation.md](variation.md) | the build's floating-point settings (GCC 8.4.0 keeps N4's float roundings: GCC bug 110182 measured; `long double` is the x87's 80-bit format), thread-count dependence (FreeSurfer's ROMP switch, every OpenMP accumulation classified and the reached ones measured, ITK at one thread), random seeds and `drand64`'s measured call order, the newest 8.2.0 update archive | relays 4 and 5 |
| `waves.md`, `queue.md`, `cards/` | the waves checked, the layout of `crates-freesurfer/`, the order of work, one porting card per program | later |

The tools behind the inventory are in `validation/investigations/freesurfer-inventory/` (they read
and print FreeSurfer's source, so they are closed too): `extract_commands.py` (the scripts' program
calls), `cmake_targets.py` (the build graph), `callgraph.py` (the call graph), `report_code.py`
(code.md's tables and code.toml), `licences.py` (third-party.md and third-party.toml), `data_refs.py`,
`data_trace.py`, `annex_check.py` and `data_files.py` (data-files.md and data-files.toml), `burkardt_compare.py`, `itk_diff.py` and `itk_functions.py` (third-party.md §9-§10), and
`drand64_order.sh` with `find_consts.py` and `gcc84/` (variation.md).
