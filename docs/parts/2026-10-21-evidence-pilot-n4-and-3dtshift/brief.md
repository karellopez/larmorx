## The verdict taxonomy (one legend for the whole site; colour plus label plus pattern, never colour alone)
- **Bit-identical**: same bytes (exit status, messages and files where the record compares them).
- **Identical with correctly rounded maths**: differs only because the original's C library (glibc's `exp`, `log`, `pow`, ...) is not correctly rounded; identical once the original uses CORE-MATH. larmorx computes the correctly rounded result. Not important; nothing to improve in larmorx.
- **Within the original's own variability**: the difference is no larger than the original differs from itself (threads, builds, versions). Not important.
- **Deliberate correction (D13)**: larmorx's default fixes a defect of the original (register entry); `reproduce` gives the original's result. Expected, an improvement.
- **Expected divergence**: the original fails, crashes or computes from undefined memory; larmorx refuses or defines the result. Expected.
- **Rejected by both**: both refuse the input with the same exit status and message.
- **Open difference**: not yet explained or above the thresholds; can still be improved (say what is known). Use it honestly where it applies (e.g. head motion is `experimental`).
Give each verdict its plain-language definition on the Validation page and link every use to it.
