# The old words: an inventory for the documentation revision

Generated by `validation/investigations/docs-revision/old_words.py` (its README says how to run it) from this repository at `6eb5f150` and the documentation site at `d9cf5fa9`. The words and what replaces them: [docs/writing-guide.md](../../../docs/writing-guide.md). The counts are of occurrences; a file is listed when it holds at least one word to change (the first seven columns).

What each column counts:

- **clean-room original**: the phrase, singular or plural, however hyphenated.
- **original = clean room**: forms in which *original* can only mean a clean room: the option's value (`implementation="original"`, `--implementation original`, still accepted for 0.1.0rc1's users, so the code that accepts it stays), a difference's label (`original − FSL 6.0.7.23`), a status in brackets (`(original)`), *the original's record* (a record belongs to a port), *LARMORX's original*.
- **exact replica**: *exact replica* and *bit-exact replica* (the word *replica* says it).
- **port as a kind**: *ported from the source*, *a port of the source*, *two (three) ways of reimplementing*: a port is any reimplementation, a replica or a clean room.
- **slogan**: *many toolkits*, *one framework*, *common computational framework*, *clean-room development practices*, *established tools* or *algorithms*, *each keeps its colour*.
- **tagline**: *into Resonance*, the user's tagline (the guide's open question 1).
- **jargon**, counted only where users read (the site's pages, data, templates, scripts and exported evidence; the README, `docs/api/`, the Python package, the evidence module, the changelog): *oracle*, *parity*, *golden*, *tier*, *night*, *D13*, *upstream*, *ecosystem*.
- **original, to read**: every other *original* or *originals*. Most name the program LARMORX is compared with, which is right; some name a clean room in forms the patterns cannot tell apart (*an original is written from a specification* on the home page, beside *when an original has a deterministic defect* on the Validation page, which is right). The rollout reads each one.

## Files named with *original*

This repository's tracked files whose name holds *original* (the site has none). *Files naming it*: how many other files of both repositories, outside what is kept as written, hold its whole name (links) and its name without the extension (links, suite and module names, identifiers). A file that a page made by a measurement links to (a record's or a benchmark report's page, which nobody edits) keeps its name until that page is made again: *renamed later*, with the pages that link to it. A record is one pair, its `.json` and its `.md` read by one name: the `.json` keeps its name while its page does.
