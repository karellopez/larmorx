# sdcflows' field-map estimation, part B

The tools behind the field maps' part B (the rest of sdcflows' estimation and correction,
niworkflows' helpers, fMRIPrep's own field-map steps): the ports of SciPy's ndimage filters,
morphology and labelling (`crates/larmorx-ndimage`, `lx.ndimage`), of scikit-image's `ball`,
`threshold_otsu` and `random_walker` (`lx.skimage`), of sdcflows' `brain_masker`
(`lx.sdcflows`) and of numpy's statistics on these paths (`larmorx_core::numpy`). Findings:
[docs/findings/scipy-ndimage-filters.md](../../../docs/findings/scipy-ndimage-filters.md),
[docs/findings/sdcflows-estimation.md](../../../docs/findings/sdcflows-estimation.md).
Sources read (permissive, `<workspace>/tags/`): SciPy 1.18.1 and 1.15.3, numpy 2.5.4 and 2.3.5,
sdcflows 2.17.1, niworkflows 1.15.4, scikit-image 0.26.0.

Run each check in both kept environments (the shared `.venv`: numpy 2.3.5, SciPy 1.15.3;
`oracles/python-newest`: numpy 2.5.4, SciPy 1.18.1), with `OPENBLAS_CORETYPE=Haswell`,
`PYTHONPATH=<repo>/python` (a wheel's `_core` copied there) and, where named,
`LARMORX_WORKSPACE=<workspace>`.
